Songmirror

Songmirror ist eine private Anwendung für einen Haushalt. Sie liest eine YouTube-Music-Playlist (Familie) und hält eine Deezer-Playlist auf demselben Stand — nur Metadaten (Titel, Interpret), keine Audiodateien.

Die Software läuft auf einem Raspberry Pi im Heimnetz. Es gibt kein öffentliches Benutzerkonto, keine Werbung und keinen Shop. Google-OAuth dient ausschließlich dazu, die eigene YouTube-Music-Bibliothek zu lesen.

  • Quelle: YouTube Music (offizielle Data API)
  • Ziel: Deezer-Familienabo, eine geteilte Playlist
  • Betrieb: Self-hosted, nicht als Cloud-Dienst angeboten
