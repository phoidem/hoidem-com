Songmirror

Private Anwendung des Domaininhabers. Sie liest eigene YouTube-Music-Playlists über die offizielle API und überträgt nur Titelmetadaten (Titel, Interpret) in eine Deezer-Playlist. Es werden keine Audiodateien heruntergeladen. Die Anwendung ist kein öffentlicher Dienst.
